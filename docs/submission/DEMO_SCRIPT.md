## Recording checks

- Derive the selected instrument and filters from the loaded run. Do not type fictional
  “successful” output into the UI or use screenshots from a different data mode without a label.
- Show the decision date and distinguish the run's creation time. Preserve the actual NO_CALL,
  factor status and abstention until a newly computed run genuinely differs.
- The cloud section must demonstrate Zetaris and Meterless, as required by the stored event
  rules. Planned architecture and a passing offline DuckDB test cannot satisfy that scene.
- Confirm actual Cursor usage and the primary track before final sponsor narration.
- Keep the recording between one and four minutes. Check that small text is readable and no
  credentials, private access documents or contact settings appear on screen.
- Review the final upload link in a signed-out browser. A script or a local recording alone
  is not the required uploaded demo video.
