# Global localization review

The historical global-localization implementation is integrated onto the verified main
baseline as the V2 proposal. See [V2_INTEGRATION.md](V2_INTEGRATION.md) for patch provenance,
the twelve-file preservation record, twelve repairs, lazy-loading architecture and limits.

Final evidence is published under `qa-reports/v2/` after testing the actual V2 implementation
commit. Historical pass counts from the old implementation are not V2 acceptance evidence.
Team-lead review, native-language editorial review, assistive-technology testing and real-device
speech acceptance remain distinct from automated browser results. No merge or deployment is implied.
